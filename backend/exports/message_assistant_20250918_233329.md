### 1. 변수 선언 및 할당
```rust
fn main() {
    // 정수형 변수 선언 및 할당
    let mut age = 25;  // `mut` 키워드로 변경 가능한 변수 선언
    println!("나이: {}", age);  // 출력 예시: 나이: 25

    // 문자열 변수 선언
    let name = "Alice";  // 문자열 변수 선언
    println!("이름: {}", name);  // 출력 예시: 이름: Alice
}
```
**설명**:
- `let` 키워드를 사용해 변수를 선언합니다.
- `mut` 키워드는 변수가 변경 가능하다는 것을 나타냅니다 (기본적으로 불변 변수로 시작하지만, 필요에 따라 변경 가능).
- 문자열은 `" "`로 감싸서 정의합니다.

### 2. 기본 제어 구조
```rust
fn main() {
    let mut number = 10;  // mutable 정수형 변수

    if number % 2 == 0 {
        println!("숫자는 짝수입니다.");  // 출력 예시: 숫자는 짝수입니다.
    } else {
        println!("숫자는 홀수입니다.");  // 출력 예시: 숫자는 홀수입니다.
    }

    for i in 1..5 {
        println!("{}", i);  // 출력 예시: 1 2 3 4
    }
}
```
**설명**:
- `if` 문을 사용해 조건문을 작성합니다. 여기서는 숫자가 짝수인지 홀수인지 판단합니다.
- `for` 루프를 통해 `1`부터 `5` 미만의 숫자에 대해 반복 출력합니다.

### 3. 함수 정의 및 호출
```rust
fn greet(name: &str) -> String {
    format!("안녕하세요, {}님!", name)  // 문자열 포맷팅 예시
}

fn main() {
    let greeting = greet("민수");  // 함수 호출 및 결과 저장
    println!("{}", greeting);  // 출력 예시: 안녕하세요, 민수님!
}
```
**설명**:
- `fn greet(name: &str) -> String`로 함수를 정의합니다. 매개변수는 참조 타입의 문자열이며 반환 값은 문자열입니다.
- `format!` 매크로를 사용해 문자열을 포맷팅합니다.

### 4. 구조체와 필드
```rust
struct Person {
    name: String,  // 이름 필드
    age: u8        // 나이 필드 (정수형)
}

fn main() {
    let person = Person {
        name: String::from("영희"),  // 구조체 인스턴스화
        age: 25                      // 나이 할당
    };

    println!("이름: {}, 나이: {}", person.name, person.age);  // 출력 예시: 이름: 영희, 나이: 25
}
```
**설명**:
- `struct Person`로 구조체를 정의하고, `name`과 `age` 필드를 포함합니다.
- 구조체 인스턴스화 시 각 필드에 값을 할당하고 출력합니다.
