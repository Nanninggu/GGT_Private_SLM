Spring Boot 자동 설정 (Auto Configuration)

Spring Boot의 자동 설정은 개발자가 수동으로 설정해야 하는 많은 보일러플레이트 코드를 자동화해주는 핵심 기능입니다.

주요 특징:
1. 조건부 설정: 클래스패스에 특정 클래스가 존재할 때만 자동 설정이 활성화됩니다.
2. 자동 구성: @EnableAutoConfiguration 어노테이션을 통해 활성화됩니다.
3. 설정 속성: application.properties나 application.yml을 통해 커스터마이징 가능합니다.

자동 설정의 동작 원리:
- @ConditionalOnClass: 특정 클래스가 클래스패스에 있을 때만 설정 적용
- @ConditionalOnMissingBean: 해당 타입의 빈이 없을 때만 설정 적용
- @ConditionalOnProperty: 특정 속성이 설정되어 있을 때만 설정 적용

예시:
- 데이터베이스 자동 설정: DataSource, JPA 관련 빈들을 자동으로 생성
- 웹 자동 설정: DispatcherServlet, ViewResolver 등을 자동으로 구성
- 보안 자동 설정: 기본 보안 설정을 자동으로 적용

이러한 자동 설정 덕분에 Spring Boot는 "Convention over Configuration" 철학을 실현하며, 개발자는 최소한의 설정으로 애플리케이션을 빠르게 개발할 수 있습니다.
